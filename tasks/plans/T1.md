## Reuse analysis

- `train`/`evaluate` in `src/train.py` already compute validation loss during
  history recording; the final validation metrics are missing and must be added.
- `setup_seed`/`save_results` in `experiments/common.py` handle reproducibility
  and complete run artifacts; reuse instead of writing new persistence code.
- `make_loaders` in `src/data/common.py` already gives paired train/validation/test
  splits from a `data_seed` and a training-stream `seed`.
- `run_experiment` already exists in both experiment modules; factor the shared
  body into `experiments/common.py` rather than duplicating it a third time in
  the grid-search driver.
- `RobustSGD` with `rho=0` is SGD; both series use the same optimizer class.

### S3: Implement grid-search core with noise-scale estimation

**Code:** new `experiments/grid_search.py` — default grids, per-seed grid
execution, cross-seed mean validation-loss selection, warmup gradient-scale
estimation, noise sweep, CSV/JSON persistence; `experiments/common.py` — a
`save` flag on the shared runner so tuning points do not write model/plots.
**Tests:** new `tests/test_grid_search.py` — deterministic fake runner verifies
minimum-mean-loss selection for both series; scale estimator checked against a
closed-form gradient norm; end-to-end tiny sweep verified by saved files.
**Docs:** README "Hyperparameter grid search" — selection rule, scale formula,
noise grid, and output layout; module docstrings for every public function.

**Spec:**
- Default lr grid `(1e-3, 1e-2, 1e-1, 1)`, rho grid `(0, 0.1, 0.3, 1.0, 3.0)`,
  seeds `(1, 2, 3, 4, 5)`, noise multipliers `(0, 0.1, 0.3, 1, 2.5)`.
- SGD series: lr grid at `rho=0` only; RSGD series: full lr x rho grid, with
  `rho=0` included. Both series run for every seed.
- For each grid point, average `validation_loss` over all seeds and pick the
  minimum; SGD yields the best lr, RSGD yields the best (lr, rho). Test data is
  never used for selection.
- Warmup: 50 updates per seed with the selected parameters, no gradient noise.
  For each batch compute per-example gradients, take the mean L2 norm of the
  flattened per-example gradient vectors, and divide by `sqrt(number of trainable
  parameters)`; average this scale over seeds. Noise values are `scale * multiplier`
  for each method.
- Noise sweep: for each method (SGD with best lr/rho=0; RSGD with its best pair),
  each seed, and each noise value, run the experiment and save full artifacts via
  `save_results`. Run names must encode method, lr, rho, and noise so no run is
  overwritten.
- Persist every grid point (all seeds and metrics) in CSV, the selection and
  per-method scale/noise grid in JSON, and a noise-sweep summary CSV under
  `<output_dir>/<experiment>/grid_search/`.
- Keep the driver free of plotting; plotting stays in `experiments/common.py`.
